# WhatsApp Business API Node.js Starter

A minimal Node.js starter using ES Modules (`"type": "module"`) and `axios` to send messages using the Meta WhatsApp Cloud API.

---

## 📋 Features

* Uses **Node.js ES Modules** (`import`/`export` syntax).
* Simple integration with Meta's **WhatsApp Cloud API**.
* Clean environment variable handling using `.env`.

---

## 🛠️ Prerequisites

1. A **[Meta for Developers Account](https://developers.facebook.com/)**.
2. A **Meta Business App** with the **WhatsApp** product added.
3. Node.js installed (v18+ recommended).
